# Employee Attrition Analysis Dashboard — Excel
## Project Overview
This project analyzes employee attrition using Microsoft Excel. The goal was to identify patterns in employee turnover and provide insights that could help an HR team better understand where attrition is occurring.
The dataset contains information on 1,470 employees across 35 variables, including age, department, job role, monthly income, job satisfaction, overtime, and years at the company.
## Tools Used
- Microsoft Excel
- Excel Tables
- PivotTables
- PivotCharts
- Excel formulas
- Data analysis and visualization
## Key Analysis
The analysis explored employee attrition across:
- Department
- Age Group
- Job Role
- Overtime
- Job Satisfaction
- Income Band
- Employee Tenure
## Key Findings
- Overall employee attrition was approximately 16%.
- Attrition varied across departments.
- The Young age group had the highest observed attrition rate among the age groups created for this analysis.
- Employees who worked overtime had a higher observed attrition rate than employees who did not.
- Attrition rates varied considerably across job roles.
- Attrition also differed across job satisfaction levels.
These findings describe patterns observed in the dataset and do not establish that any individual factor directly causes employee attrition.
## Dashboard
The Excel dashboard summarizes the analysis using KPI cards, PivotCharts, and interactive visualizations.
